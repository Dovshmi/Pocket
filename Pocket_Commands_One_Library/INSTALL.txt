Pocket single-command-library update

1. Download the full source: https://github.com/Dovshmi/Pocket/archive/refs/heads/main.zip
2. Extract it to a folder named Pocket.
3. Copy the commands folder from this ZIP into that Pocket folder, merging folders as necessary.
4. Run install.bat once, then run.bat.
5. The Commands menu loads ONLY commands/commands.json.

The file has 573 original records and 35 named categories. Empty categories have no invented CLI commands.
Do not publish commands.json: this is your private source workbook-derived reference, not part of the public GitHub repository.
