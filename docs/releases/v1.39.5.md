# Pocket v1.39.5 — Compact Quick Slot Dialogs, Clipboard History and Tray Shortcuts

**Stable Windows patch · Windows 10/11 · Local/offline-first**

## Highlights

### Smaller-looking native Windows notifications
Quick Slot Save, Auto Paste and Copy-to-Clipboard use the same system-managed Windows notifications as before. Their titles are shorter and the preview is shortened by approximately 10%, from 120 to 108 characters. The physical size of the notification is controlled by Windows, not Pocket.

### Clearer replacement confirmation
When you replace an occupied Quick Slot, a compact Pocket dialog displays the **new value on the left → old value on the right**. The number of the Quick Slot appears in the title, values are shortened to fit, and **Yes** replaces while **No**, Escape or closing the dialog cancels.

### Preserve replaced Quick Slot text
When you choose Yes:
- If the previous value is present in today's regular Clipboard history, Pocket reuses the existing record and removes its Pin (no duplicate).
- If it is absent, Pocket adds an ordinary **unpinned** history item before changing the slot.
- Works with both in-memory **RAM** and optional persisted **DATABASE** Clipboard history.
- If storing the old text fails, replacement is cancelled and the previous Quick Slot remains assigned.
- When the sensitive-text filter forbids the old text from being copied to history, replacement is blocked to avoid silently losing it. Review sensitive content and filter settings before replacing.

Existing clipboard history, current settings and the new assigned Quick Slot are otherwise preserved. Replacing a slot still requires explicit confirmation.

### Improved right-click menu for the Pocket tray icon
The system tray menu now has these five actions, in order:
1. **Open Pocket**
2. **Open Settings**
3. **Create Backup**
4. **Restore Backup**
5. **Exit Pocket**

These actions reopen Pocket's **existing** Settings, Backup and Restore dialogs on its main UI thread. No new background service, account or network operation is introduced.

## Windows release packages

- **Pocket-Portable-v1.39.5.zip** — self-contained portable distribution
- **Pocket-v1.39.5.exe** — standalone Windows executable
- **SHA256SUMS.txt** — integrity checksums

The release workflow builds and tests both Windows packages, runs the unit tests, Windows hotkeys and copy/paste integration, validates a real on-screen replacement dialog and checks the packages for private data before publishing.

## Upgrade

Fully exit Pocket from the Windows tray. Back up your existing portable `data/` directory. Extract the new ZIP into a **separate** location and copy `data/` to the new portable app. Do not mix older `_internal/` Python runtime files with the new release.
