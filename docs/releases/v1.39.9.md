# Pocket v1.39.9 — Reminders

**Offline-first Windows productivity toolkit · Reminders and notification UI**

Version 1.39.9 introduces a dedicated Reminders hub while preserving the established Notes, Quick Slots, Clipboard, Commands, Subnet, Shortcuts, Port and MAC tools.

## Highlights

- **Standalone and Note-linked reminders:** Create independent reminders with editable titles and optional details, or attach a reminder to any existing Note. Everything remains local.
- **Compact Pocket reminder dialogs:** Clear TITLE and NOTE sections, scrollable read-only content, theme-matched buttons and a separator between saved information and an optional response input. The input appears only when enabled and can save a timestamped reply.
- **Snooze choices:** One popup menu with 5, 10, 15, 20, 30, 40, 45, 50, 60, 90 and 120 minutes.
- **All / Upcoming / Snoozed / Done:** Compact filter tabs and status counters; optional local search.
- **Small green Add icon and text-only Clear:** Add directly below Search. Clear requires a warning/confirmation and affects the selected status tab. Note-linked reminders are cleared without deleting their Notes, titles, or content.
- **Mini navigation:** More / Less expansion adds Reminders without relocating the original first-row tool icons.
- **Master Reminders switch:** Hiding the Reminders tool disables due alerts for both independent and Note-linked items. Schedules and drafts survive re-enabling and restarts.
- **Reliable offline storage:** Reminder state is stored in `data.json`, included in selective Notes & reminders backups and guarded by recovery checks and rollback.
- **Settings version:** `v1.39.9`.

## Package safety

The Portable ZIP includes only public example commands and required application binaries; private notes, clipboard history, passwords, user data and command libraries are not bundled. The release workflow verifies the package manifest, native runtime files, standalone executable, UI startup and SHA-256 checksums before publishing.

## Installation

The **Portable ZIP** is the simplest option for most Windows workstations: extract all files to a new writable local directory, keep `_internal` beside `PocketDesk.exe`, and run the executable. The **Standalone EXE** stores user data under `%APPDATA%\PocketDesk\`.

Before upgrading, exit Pocket fully and create a Backup & Restore ZIP or preserve the entire existing `data` directory. Do not merge old and new `_internal` folders.

**Release validation:** The Windows release workflow must pass compilation, unit tests, interactive GUI smoke tests, packaging integrity, portable and standalone runtime startup checks, and SHA-256 generation before publishing these assets. If validation fails, no completed v1.39.9 release should be announced.
