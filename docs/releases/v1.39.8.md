# Pocket v1.39.8 — Roomier Native Quick Slot Replacement

**Focused Windows UI patch · Portable ZIP / Standalone EXE · Offline-first**

## What's changed

When saving a new value over an existing Quick Slot, Pocket still uses the **original Windows Yes/No MessageBox**, not a custom Tkinter popup.

The confirmation now uses slightly more descriptive labels:

```text
Replace Quick Slot [2]?

Old text: SVLAN 1557
↓
New text: SVLAN 11
```

The maximum preview length was increased from **23 to 30 characters** per value, so more of each text is visible. The labels are a little wider, giving the Windows dialog more room for ordinary short values. Windows decides the final window size automatically; this change does not enforce an exact pixel width.

**Yes** replaces the Quick Slot while preserving displaced text in ordinary unpinned Clipboard history. **No/Escape** cancels without changing anything.

## What is *not* part of this patch

Notes reminders, improved time selection, text input with optional append-to-note, Snooze, and a potential reminder dashboard are **not implemented** here. All current Note notification behavior remains intact; those features can be designed in a follow-up.

Quick Slot notification labels, custom notification preferences, tray features, backup/restore, and existing shortcuts are unchanged.

## Release files

- `Pocket-Portable-v1.39.8.zip` — self-contained Windows portable build
- `Pocket-v1.39.8.exe` — standalone Windows executable
- `SHA256SUMS.txt` — build integrity checksums

Exit Pocket from the system tray before upgrading. For the portable version, back up `data/`, extract the new release in a separate directory, then copy your previous `data/` across. Never mix different releases' `_internal/` files.
