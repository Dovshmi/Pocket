# Pocket v1.40.0 — Excel Lookup, Mini Navigation & Outlook SOC

Pocket **v1.40.0** is the official Windows release, distributed as a tested **Portable ZIP** and **standalone EXE**, built from the `main` source.

## What is new

### Extra: local Excel search and optional offline database
- Search authorized Excel workbooks **read-only** on the local computer, including all worksheets and populated columns.
- Optionally build an indexed **local SQLite database** using an explicit Sync command. Subsequent database searches work offline without reopening Excel. No automatic uploads or background synchronization.
- Browse the compact matched-row summary, relevant line/group, VDOM/VRF and FortiGate details when safely derivable. Access all additional populated columns.
- Mini MATCHES features a slim results scrollbar and keyboard Up/Down; Left/Right changes the selected result when its details are focused.

### Excel shortcuts and Outlook SOC
- Excel shortcuts try to activate a workbook already open by matching its full path, rather than opening a duplicate. Opening a distinct workbook does not close the existing one.
- The **Outlook · SOC** action builds an **unsent draft** from the selected row. Missing contact, expert approval and ticket information is intentionally left for manual completion; no email is sent automatically.

### Better Mini menus and Settings
- Reorder Mini toolbar icons directly with drag-and-drop.
- Hide a tool from its right-click menu without deleting data; restore it with the trailing Add (+) or Settings → Show / Hide.
- **Green = active**, **red = hidden** in Settings; simplified menu control and improved More/Less behavior.

### Included from prior stable releases
- Notes and independent reminders with Snooze, Clipboard history and nine Quick Slots.
- CLI Commands Helper, subnet calculator, Quick Shortcuts, local and opt-in DashDash TCP/MAC checks, backup/restore, themes and Windows proxy handling.

## Upgrading safely

1. Exit the previous Pocket process fully, including its tray icon.
2. Back up your current `data/` folder or use Settings → Backup & Restore.
3. Extract the new Portable ZIP to a **new directory**. Do not mix versions of `_internal/`.
4. Copy the saved Portable `data/` folder into the new `Pocket-Portable/` folder, or retain the current application profile for standalone.
5. Verify notes, reminders, shortcuts and settings before returning to daily use.

[Previous stable v1.39.9 release](https://github.com/Dovshmi/Pocket/releases/tag/v1.39.9) remains available for rollback.

## Verification, privacy and compatibility

The Windows release pipeline runs unit tests, GUI checks (including v1.40 menu/Extra navigation), keyboard and Clipboard regressions, builds the ZIP/EXE, verifies ZIP contents and SHA-256 checksums, tests a freshly extracted Portable executable and a standalone dependency/GUI startup. The release is published only if all gates pass.

**Workstation-specific limitations:** GitHub CI cannot reproduce enterprise IRM/Office permissions, real protected Excel workbooks, Outlook installation/COM access or company policy for storing local data. Test these functions on an authorized work PC using the [acceptance checklist](https://github.com/Dovshmi/Pocket/blob/main/docs/RELEASE_CHECKLIST_V140.md).

**Local data notice:** The optional offline SQLite database and backup ZIP files are **not encrypted**. Only synchronize datasets where your organization permits local storage. No private customer workbooks, databases, passwords or custom command libraries are bundled in the official downloads. Network calls are limited to explicitly requested remote checks or opened links.

**Unsigned Windows builds:** Corporate application-control may block the app. Do not bypass security policies.
