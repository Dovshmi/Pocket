# Historical manual GUI scenarios

These scripts record earlier Pocket UI tests, often with legacy screenshot names or obsolete widget assumptions. They are kept for reference, not run by the automated CI suite. Run the maintained `tests/integration/smoke_dashboard_integration.py` for current cross-layout validation.

From the repository root, use `python -m tests.manual.smoke_<name>` to run an individual legacy script where still applicable. Do not treat its screenshots as the current UI design.
