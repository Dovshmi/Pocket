# Pocket v1.39.9 — Reminders (development)

**Work in progress, not published.** The latest public release remains v1.39.8.

## Features

- **Own Reminders icon and expandable Mini navigation:** Mini retains the original eight fixed-width icon **positions** in its first row. With seven tools and Settings, the last More icon opens Settings directly as before. When Reminders (or more future tools) is enabled, the last icon changes to a **More / Less** expander. Clicking More displays additional icon rows of up to eight positions; with the current defaults, the second row contains only **Reminders** and **Settings**. Clicking Less collapses them; the first row does not move. Reminders also appears in the Normal and Dashboard tool menus and can be hidden in Visible tools.
- **Compact, themed calendar and time:** The Note scheduler has been reduced from **425×522 to 366×445 pixels** and uses the user's selected Pocket palette rather than a light calendar. Day selection, 00–23 hours and 00–59 minutes remain available. Quick times are in one **Dropdown**: Custom time, +15 minutes, +1 hour or Tomorrow 09:00. Selecting a preset automatically sets the date/time and **disables (greys) the manual hour/minute fields**. Returning to Custom or clicking a calendar date re-enables them.
- **Compact Pocket-themed due dialog:** The popup automatically fits its visible content rather than pinning the footer to the bottom of a tall fixed window. Clear **TITLE** and **NOTE** labels, a slim accent alongside read-only Note text, and a subtle divider separate the saved reminder from the optional response. A response editor is **completely hidden** when unchecked, appears when checked, and resizes the popup without losing a draft. **Snooze**, **Done**, and **Dismiss** use theme-colored Tk controls instead of white native ttk buttons. Full long Notes remain scrollable. The window works even when Pocket is hidden.
- **Timestamped, opt-in response:** Until **Add response** is checked, the input is disabled and cannot accept typing or paste. If checked and nonblank on Done/Dismiss/Escape/close, the Note gets a new block at the **very bottom**: local **DD/MM/YYYY HH:MM** on its own line, followed by the customer's response on the next line. The existing Note text is preserved byte-for-byte. If unchecked or blank, the Note body is not changed.
- **Single-button Snooze menu:** Both Reminder cards and due popups have one themed **Snooze ▾** button; it opens a short menu (5, 10, 15, 20, 30, 40, 45, 50, 60, 90 or 120 minutes). Selecting a time postpones immediately—no second confirmation, permanent dropdown or extra button. The card places **Snooze** and **Change time** on the same compact row. Response drafts and checkbox state are retained across Snooze and restart.
- **Redesigned Reminders hub:** A dedicated polished, Pocket-themed page with a clear **+ New** action, three compact status counters, filter tabs (**All / Upcoming / Snoozed / Done**), local search, clean compact cards, and source labels (**Note** vs **Reminder**). The card actions adapt to each type without overcrowding Mini.
- **Standalone reminders (without Notes), calendar-first:** **+ New** opens **only the compact date/time picker**. Confirming the time immediately creates a standalone reminder card inside the Reminders menu with default title **New reminder**; its title Entry is selected for direct typing. The card contains an editable **Note · Optional** text area immediately **below the title**, with local debounced autosave; the title and Note can be modified later in-place without opening another window. The card's **Change time** button opens only the date/time picker again. Empty titles are prevented and never corrupt stored data. These records live in `data.json.reminders`, not `data.json.notes`; no empty/hidden Note is ever created. one-button Snooze, compact ✓/× actions, Reactivate, and optional timestamped due-time replies operate on the standalone record.
- **Invisible but functional Reminder scrolling:** The entire Reminders page now uses the existing canvas-based scrolling engine without displaying a vertical scrollbar. Mouse wheel and touchpad work in Mini as well as in larger layouts; text areas retain their native internal scrolling until their own edge.
- **Compact Reminder actions and reactivation:** Each card has a top-right **✓** to mark an active Reminder done and **×** to remove it (with confirmation). For Note-linked Reminders, × removes only the scheduled reminder, never the Note or its body. A completed reminder shows **Reactivate** (English), reopening the time picker to schedule its next occurrence. The ✓ remains neutral for Upcoming and only becomes themed blue/accent when Completed, while staying non-interactive. Status text uses sentence case, not ALL CAPS; Upcoming and Snoozed have no special completion color.
- **Complete text when a reminder fires:** Due Reminder dialogs show the full title and the complete Note body (for Note-linked items) or complete Note/details field (for standalone items). Long text can be scrolled inside a borderless, background-matched, read-only text viewer that looks like Reminder content rather than a second input; no text is silently truncated to a short preview. The optional response checkbox, input and Snooze controls remain below that content.
- **Smaller status counters:** Upcoming, Snoozed and Done are now compact, one-line mini counters (instead of oversized two-line cards), saving precious vertical room in Mini for editable Reminder cards.
- **Backup and restart:** Standalone records, Snooze state and response history persist locally and are included in the **Notes and reminders** backup category (legacy backups without the new field still import). Failed saves roll back the pending change.
- **Safety:** Showing a reminder does not mark it complete. If Pocket is restarted before an answer, the reminder will reappear. Failed local saves roll back the in-memory change; an unsent draft requires confirmation before being discarded from the overview.
- **Reminders menu is the master notification switch:** Unchecking **Reminders** under Visible tools silences both standalone and Note-linked due notifications, disables Notify me/Change time in Notes and dismisses any already-visible popup without completing it. Scheduled times, previous replies and unsent drafts remain stored. Rechecking the menu resumes reminders, including those that became overdue while off. This setting survives app restart and applies to all display modes.
- **Offline-first:** No sign-in, external DB, internet calls or additional dependencies.
