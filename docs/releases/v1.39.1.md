# Pocket v1.39.1 — Reliable Quick Slots Paste

**Stable patch release · Windows 10 / 11 · offline-first**

This patch addresses Quick Slots paste errors on Windows, including OLE
clipboard snapshot failures reported as `CloseClipboard Failed`, and adds a
simple manual-paste alternative.

## Improvements

### Auto Paste (existing default)

Press the configured Paste prefix + **Numpad1–9** (default
`Ctrl+Alt+NumpadN`). Pocket inserts the stored slot text as native Windows Unicode input and never
borrows, replaces, or restores the Windows clipboard.

Auto Paste no longer calls Windows OLE at all, avoiding clipboard snapshot
and restoration failures such as `CloseClipboard Failed`. Existing copied text,
images and other formats are left untouched. Protected, elevated or specialized
terminal programs may reject native injected input; use Clipboard Only there.

### Copy to Clipboard (new option)

Open **Settings → Clipboard & privacy → Quick Slot paste behavior** and choose
**Copy to Clipboard**. Press the same Quick Slot Paste shortcut to make its
content the current Windows clipboard. Then press normal `Ctrl+V` in the
target application whenever you are ready.

This mode deliberately **replaces** the current clipboard instead of trying
to preserve and restore it. Pocket sends no automatic paste keystroke. The
choice persists after restart, and previously saved user profiles default to
Auto Paste.

## Unchanged

The nine persistent slots, two separate configurable modifier prefixes,
clipboard monitoring preferences, Notes, CLI, network tools and portable
Backup/Restore work as before. Slots and their preferences remain excluded
from exported profile backups. No cloud service or background network access
is introduced.

- **Pocket-v1.39.1.exe**: standalone Windows EXE
- **SHA256SUMS.txt**: SHA-256 digests for both artifacts

The Windows release workflow runs unit regressions, Windows GUI/hotkey
tests, Windows build checks, privacy/ZIP validation and packaged startup
checks. Compatibility with a particular restricted workplace application
still requires testing on that actual workstation.

## Upgrade safely

1. Fully exit Pocket (including the system tray).
2. Back up the existing profile data.
3. Extract v1.39.1 portable ZIP into a **new** folder; do not mix `_internal/`
   binaries from different releases.
4. Copy only the previous `data/` folder into the new portable installation,
   or keep the existing `%APPDATA%\PocketDesk\` profile if using standalone.
5. Confirm your saved slots, paste behavior and Notes.

Unsigned Windows binaries may be blocked by corporate policy; do not bypass
organization controls.
