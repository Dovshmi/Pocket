# Pocket v1.39.7 — Polished Quick Slot Notifications and Clear Replacement

**Stable Windows 10/11 update · Offline-first · Portable + standalone EXE**

This maintenance release adjusts only the wording of Quick Slot prompts and native Windows notifications.

## Native Windows notifications

Quick Slot notifications now use normal capitalization:

| Situation | Title | Body |
|---|---|---|
| Save/Copy text to Slot 3 | `Pocket · Copy [3]` | The copied text preview |
| Paste text from Slot 3 | `Pocket · Paste [3]` | The pasted text preview |
| Save unchanged text to Slot 3 | `Pocket · Unchanged [3]` | The already-saved text preview |

The `Unchanged` title stands alone and does not repeat `Copy`. Error titles also use sentence case. Physical notifications still use Windows' native layout and remain controlled by the single Settings → Clipboard & privacy → Quick Slot notifications selector.

## Native Windows replacement confirmation

Replacing an existing Quick Slot still shows the system **Yes / No MessageBox**, not a custom Tkinter window.

Example title: **Replace Quick Slot [2]?**

Text (displayed vertically):

```text
Old: SVLAN 1557
↓
New: SVLAN 11
```

Both text previews are shortened as before to keep the system dialog compact. Choosing No leaves the slot and history unchanged. Choosing Yes retains displaced text as ordinary unpinned Clipboard history as introduced in v1.39.5.

## No other changes

- Quick Slot hotkeys and Save/Paste behavior settings are unchanged.
- The right-click tray actions, backup/restore workflow, clipboard modes, and offline-first design are unchanged.
- No login, background network activity, or data migration is introduced.

## Release artifacts

- `Pocket-Portable-v1.39.7.zip`
- `Pocket-v1.39.7.exe`
- `SHA256SUMS.txt`

Close Pocket completely using Exit Pocket from the tray before upgrading. For the portable version, back up `data/` and extract the new archive into a fresh directory. Do not mix `_internal/` runtime files between versions.
