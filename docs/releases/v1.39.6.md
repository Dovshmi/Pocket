# Pocket v1.39.6 — Native Quick Slot Confirmation and Optional Windows Notifications

**Stable correction release — Windows 10/11 — Offline-first**

## What's fixed

### Native Windows confirmation for Quick Slot replacement

The previous custom Tkinter confirmation has been removed. Pocket again calls the original **Windows Yes / No MessageBox** when you overwrite a saved Quick Slot. A concise line shows:

**NEW: SVLAN 11   →   OLD: SVLAN 1557**

The title identifies the slot (e.g., **Replace Quick Slot [2]?**). Previews are truncated to fit in a system-sized dialog. **No** or Escape leaves everything unchanged.

### COPY/PASTE notifications without repeated labels

Windows still owns the notification visuals. Example:

- **Title:** Pocket · COPY [3]
- **Body:** SVLAN 11

Or:

- **Title:** Pocket · PASTE [3]
- **Body:** SVLAN 11

No redundant `Saved:`, `Pasted:` or `Copied:` text in the body. For **Copy to Clipboard** mode, the title reads `COPY` and the body is only the text preview; manual `Ctrl+V` is still required.

### One simple preference to choose what shows notifications

Under **Settings → Clipboard & privacy → Quick Slot notifications**, choose:

| Choice | Copy/Save notices | Paste notices |
|---|---|---|
| **Copy + Paste** (default) | On | On |
| **Copy only** | On | Off |
| **Paste only** | Off | On |
| **Off** | Off | Off |

The setting affects Quick Slot success and failure feedback only. **Note reminders and unrelated alerts are not silenced**. The choice is stored locally and retained after restart. Like existing Quick Slot settings and contents, it is excluded from Pocket ZIP backup and can be reset with other keyboard preferences.

## Everything else retained from v1.39.5

- Replacing a Slot retains the displaced text as ordinary **unpinned Clipboard history**, even if it wasn't previously recorded (RAM or DATABASE mode).
- The tray right-click menu includes Open Pocket, Open Settings, Create Backup, Restore Backup, Exit Pocket.
- No extra internet calls, background services, sign-in, or migration of existing private data.
