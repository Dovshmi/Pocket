# Pocket v1.39.2 — Hebrew and Multilingual Quick Slots Auto Paste

**Stable Windows 10/11 patch release**

This patch fixes stored Hebrew text turning into question marks when the
Auto Paste shortcut is used in some corporate or remote Windows programs.
These applications may misinterpret Unicode keystrokes injected through
`SendInput(KEYEVENTF_UNICODE)` even though they accept normal clipboard
pasting.

## What changed

- **English, digits and other ASCII-only slot text:** Pocket continues
  inserting text directly using the clipboard-independent input path
  introduced in v1.39.1.
- **Hebrew or other non-ASCII slot text:** Pocket writes the slot to the Windows
  clipboard as **CF_UNICODETEXT (UTF-16)** and sends ordinary **Ctrl+V** to the
  currently focused application. No conversion to ANSI is performed, so
  text such as `שלום עולם 123` retains its Unicode characters.
- **No OLE snapshot/restore:** This route does not invoke `OleGetClipboard`,
  `OleSetClipboard` or `OleFlushClipboard`, avoiding the previous
  `CloseClipboard Failed` errors.

**Important clipboard behavior:** Auto Paste of Hebrew/multilingual text
replaces the existing clipboard and leaves the slot text there after pasting.
Unlike ASCII-only paste, it does **not** preserve old copied text/images.
This tradeoff is intentional and safer than attempting a fragile OLE
multi-format restore. You can also choose the existing **Copy to Clipboard**
mode in **Settings → Clipboard & privacy → Quick Slot paste behavior** to
stage any text manually and paste with `Ctrl+V` later.

## Remains unchanged

The nine persistent Quick Slots, copy/save key combinations, app layouts,
Notes, network tools, offline-first behavior, manual Clipboard Only mode,
portable Backup/Restore, and profiles from v1.39.1 remain compatible.

## Downloads

- `Pocket-Portable-v1.39.2.zip` — self-contained Windows portable package
  with native DLLs, manifest and verification script
- `Pocket-v1.39.2.exe` — standalone Windows executable
- `SHA256SUMS.txt` — SHA-256 hashes of both release packages

The release workflow checks units and the real Windows clipboard/keyboard
paths, including Hebrew and mixed-language text, before publishing. Real
customer/remote application compatibility still depends on the target
application's native Ctrl+V support.

## Safe upgrade

1. Fully exit Pocket from the system tray.
2. Back up your data: portable installations use `Pocket-Portable/data/`;
   standalone installs use `%APPDATA%\PocketDesk\`.
3. Extract the new portable ZIP into a **new** folder, preserving its complete
   `_internal/` contents. Do not mix old and new bundled DLLs.
4. Copy your old portable `data/` folder to the new installation if needed.
5. Verify an ASCII Quick Slot and a Hebrew Quick Slot in your target app.
   For Hebrew, confirm that the characters are not replaced by question marks.

The EXE packages are unsigned; follow workplace application policies.
