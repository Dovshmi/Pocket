# Pocket v1.39.3 — Independent Quick Slot Save and Paste Controls

**Stable patch · Windows 10/11 · Offline-first**

This release gives the nine Quick Slots two independent behavior settings,
without changing the configured Numpad hotkeys or existing saved slot data.

## Settings → Clipboard & privacy

### Quick Slot save behavior (Copy/Save shortcut)

- **Auto Copy Selection (default):** Pocket sends Ctrl+C to the foreground
  app, saves selected text to slot N, and falls back to existing Windows
  clipboard text when no fresh selection arrives.
- **Use Current Clipboard:** You manually copy text first (Ctrl+C or the
  application's Copy command). Pressing the Save shortcut then reads existing
  Unicode text and saves it to slot N. Pocket **does not send Ctrl+C** in
  this mode; empty/non-text content produces a clear error.

### Quick Slot paste behavior (Paste shortcut)

- **Auto Paste (default):** Inserts text automatically. ASCII-only text uses
  direct input without touching the clipboard; Hebrew and other non-ASCII
  text use Windows Unicode clipboard and simulated Ctrl+V.
- **Copy to Clipboard:** Places the slot into the clipboard without
  automatically pasting anything. Press **Ctrl+V manually** in the desired
  application.

The two selectors are completely independent: all four combinations work.
Your choices persist after restarting Pocket, while users upgrading from
v1.39.2 keep their previous Paste preference and default to Auto Copy
Selection for Save.

**Compatibility note:** Some remote, enterprise, or specialized Windows
programs reject simulated paste, or convert Hebrew to question marks. For
those programs, select **Copy to Clipboard** for Paste and use real Ctrl+V.
This does not guarantee that every destination program supports Unicode.

## Safety and privacy

- Existing notes, profiles, quick slots, hotkey combinations, and tray modes
  remain unchanged.
- Saved Quick Slot text and Quick Slot-specific settings remain excluded
  from portable exports. Existing manual replacement confirmation and
  sensitive text checks are retained.
- Clipboard reading, copying, and pasting never require internet access.

## Official Windows packages

- **Pocket-Portable-v1.39.3.zip** — Windows portable installation
- **Pocket-v1.39.3.exe** — standalone EXE
- **SHA256SUMS.txt** — integrity checksums

The build pipeline runs the complete unit suite, Windows GUI and hotkey
integration, multilingual paste checks, and packaged Windows startup checks
before publishing.

## Upgrade

1. Fully exit Pocket from the tray.
2. Back up your existing `data/` folder (portable install).
3. Extract the new ZIP into a separate directory with the matching
   `_internal/` runtime, then copy the existing `data/` into it.
4. Try both selectors in Settings and use a Hebrew Quick Slot in the
   particular target program.
