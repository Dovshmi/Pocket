# Pocket v1.39.4 — Clearer Quick Slot Notifications and Shortcut Defaults

**Stable patch · Windows 10/11 · Offline-first**

## Changes

- Native Windows notifications now identify **Quick Slot 1–9** and show a short preview (maximum **120 characters**) of the text that was saved, pasted, or copied to the Windows clipboard.
- **Auto Paste** notifications say *Pasted from Quick Slot N*. **Copy to Clipboard** notifications say *Copied Quick Slot N to clipboard* and instruct the user to **Press Ctrl+V to paste**. The app never falsely reports an automatic paste in clipboard-only mode.
- Already-saved notifications display the existing value, and error messages identify the affected slot.
- The new default **Save/Copy shortcut** for new profiles and Keyboard Settings reset is **Ctrl+Alt+Win+Numpad1–9**. The **Paste shortcut** remains **Ctrl+Alt+Numpad1–9**. Current user preferences, existing Quick Slot values, and separate save/paste behavior selectors are unaffected.
- Removed the **Record paste shortcut** and **Record save shortcut** buttons from Settings. Modifier dropdowns remain, and the unrelated Popup/Translate shortcut recorder is preserved.

## Privacy and limitations

Native Windows notifications can remain in the Windows notification history. The visible preview is display-only and does not truncate saved data. Avoid storing credentials, secrets, or customer data in Quick Slots. The existing sensitive-content filter, slot replacement confirmation, and local-only storage remain in place. A conflicting global Windows shortcut may be unavailable depending on workstation policy.

## Windows release assets

- **Pocket-Portable-v1.39.4.zip** — self-contained portable package
- **Pocket-v1.39.4.exe** — standalone Windows executable
- **SHA256SUMS.txt** — hashes for both executables

The release pipeline validates the Python sources, unit tests, Windows GUI/shortcut tests, the portable ZIP privacy and integrity, and startup of the packaged Windows builds before it publishes these assets.

## Safe upgrade

1. Fully exit Pocket via its Windows tray icon.
2. Back up your existing portable `data/` directory.
3. Extract the new ZIP into a **new** folder, keeping its matching `_internal/` folder.
4. Copy your existing `data/` into the new portable folder.
